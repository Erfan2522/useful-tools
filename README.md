# Useful Tools 🛠️

مجموعه‌ای از ابزارهای کاربردی وب با پشتیبانی از زبان فارسی 🇮🇷 و انگلیسی 🇬🇧

A collection of useful web tools with Persian 🇮🇷 and English 🇬🇧 language support.

---

## ✨ امکانات | Features

- 🔐 رمزساز حرفه‌ای | Professional Password Generator
- 📱 ساخت QR Code | QR Code Generator
- 🌐 پشتیبانی از فارسی و انگلیسی | Persian / English support
- 🌙 رابط کاربری مدرن و واکنش‌گرا | Modern responsive UI
- 📱 سازگار با موبایل | Mobile-friendly design
- ⚡ سریع و سبک | Fast and lightweight
- 🧰 مجموعه‌ای از ابزارهای کاربردی روزمره | Useful everyday web tools

---

## 🚀 استفاده | Usage

### فارسی 🇮🇷

برای استفاده کافی است فایل `index.html` را با مرورگر باز کنید.

### English 🇬🇧

Simply open `index.html` in your browser.
